# 架构决策记录

本目录用于存放 ADR，即重要架构和技术决策的简短记录。

在选择或变更以下内容时，应创建 ADR：

- 应用框架
- 编程语言/运行时
- 数据库
- API 风格
- 队列或异步处理技术
- 缓存技术
- 部署平台
- 外部服务依赖
- 安全或可观测性方案

## 命名

使用递增编号文件名：

```text
0001-short-decision-title.md
0002-another-decision.md
```

## ADR 模板

```markdown
# ADR 0000：决策标题

## 状态

Proposed | Accepted | Superseded | Rejected

## 日期

YYYY-MM-DD

## 背景

什么问题或约束要求做出决策？

## 决策

最终做出了什么决策？

## 已考虑选项

- 选项 A：
- 选项 B：
- 选项 C：

## 影响

该决策带来的正面和负面影响。

## 验证

如何在实现、测试或运行中验证该决策？

## 相关文档

- 链接到产品、架构、模块或之前的 ADR 文档。
```
